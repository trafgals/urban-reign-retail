# Urban Reign Retail (WebAssembly Port)

A deterministic, hardware-accelerated 60Hz browser re-implementation and WebAssembly port of the original **Urban Reign** retail release (Namco, 2005) running on modern WebGPU.

## Features
- **Zero-Install Web Play**: Runs directly in Google Chrome, Microsoft Edge, or Safari with WebGPU enabled.
- **Full Stage Music Preserved**: 100% of all 73 original BGM soundtrack streams are preserved in full fidelity.
- **Auto-Skip Cutscenes**: Missing/stripped video sequences automatically skip directly into gameplay.
- **On-Demand Brotli Disc Streaming**: Chunks stream over HTTP range requests under GitHub Pages limits.
- **Persistent Memory Card**: 8 MB PS2 memory card mounted directly in IndexedDB with export/import support.
- **Companion Mod**: Check out [Urban Reign Redux 0.4](https://trafgals.github.io/urban-reign-web/) for the enhanced balance & Tekken characters mod edition.

## Controls
- **Movement**: Arrow Keys / Left Stick (I, J, K, L)
- **Attacks**: Z (Strike), X (Grapple), A (Special Arts), S (Dodge/Evade)
- **Combat Target Cycle**: Q / W
- **Start / Pause**: Enter
- **Select**: Backspace
- **Gamepad API**: Plug-and-play support for standard USB/Bluetooth controllers.
